### The Matrix Bros

A vibe coded mashup of Matrix meets Super Mario using the Ornith-1.5-35B-Q4_K_M model on a 6GB VRAM machine with 64 GB Ram. Total time to generate with a couple fix prompts and hand fixes - about 2 hours, averaging about 20TPS. It's not a full game, just the first level, and while it's not perfect - it's absolutely a great start. 

**Here's the prompt that generated this:**
Write a fully functional, complete clone of Super Mario Bros game (the famous NES game)
Only replace it with visuals and characters that look more like characters from the movie "The Matrix".
- Clone must work in a web browser, index.html, no server
- Decent replica of the graphics assets.
- Colorful and playable.
- Controls with keyboard up, down, left, right, spacebar to jump, shift to speed up
